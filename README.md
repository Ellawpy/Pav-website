# Ella & Pav — Creative Duo Portfolio

A single-page portfolio (vanilla HTML + in-browser React/Babel). No build step.

## Run locally
Open `index.html` in any modern browser.

## Deploy (GitHub Pages)
Push this folder to a GitHub repo, then enable Pages (Settings → Pages → Branch: main / root).
The `.nojekyll` file ensures asset folders (with spaces) and `lib/` are served as-is.
